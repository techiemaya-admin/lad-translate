Session

Live transcript …

What the speaker said and what went out in each language, as it happens. The tiles say a session is healthy; only this says the words are right — read the first minute of any new room here.

Preset deck

Press a pad to arm a preset, ride the faders if you must, then hit Apply. The lit pad is what the box is running now. Amber LEDs mean the preset carries a warning — read it in the display before you take it to a room.

Recordings …

The speaker and every translation, as WAV files on the same clock — silence stands in for the gaps, so the tracks line up in any editor. Recording is disclosed on the speaker and listener pages while it is on. Files stay on this box until deleted here.

QR codes

Room URLs, so they survive a restart. Scan the speaker code and start talking before joining as a listener.

Hardware output …

The venue's rig: which language goes out on which Dante channel, and which IR handset number that is. Kept per venue, not per session — re-patching in software before every event is the step this removes.

New device

One language per channel; a language may take several channels (the transmitter and a recorder at a different level is ordinary). The IR number is what is printed on the handset signage and is kept separate from the channel index on purpose.
